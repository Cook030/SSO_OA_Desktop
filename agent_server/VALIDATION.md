# 本轮验证记录（2026-09-07）

- Python：25 个测试通过，使用真实 LangGraph、SQLite checkpoint 和 FastAPI；模型及 OA 请求使用隔离替身。
- Ruff：检查、格式检查通过。
- 数据库：启动时按 ORM 模型自动建表（幂等），实际 FastAPI 生命周期启动通过；生命周期内断言 7 张业务表均已创建。

- 前端：4 个事件流测试通过，覆盖 SSE 分片、CRLF、多事件、UTF-8 拆包及 Bearer 不入 URL。
- TypeScript 类型检查与 Vite 生产构建通过，JS 约 15.3 KiB，gzip 约 5.9 KiB；没有前端运行时 npm 依赖。
- Go：原有测试与构建通过。
- Wails：生产打包成功，使用已经验证的前端产物，生成 `workbench/build/bin/workbench.exe`。绑定仅保留 Desktop。
- Docker Compose：配置语法验证通过。
- 浏览器：隔离测试服务中，登录、发送任务、进度、确认卡片、拒绝计划和恢复输入已验证；截图检查了三栏布局。

确认前不写入、拒绝不写入、重复确认不重复提交、参数篡改拒绝、跨用户隔离、权限被撤回、计划过期、角色/权限点变化、OA 拒绝、写入超时、写入成功但回查被拒绝、持久化 checkpoint 重开连接后恢复、服务重启不重放写入、SSE 游标重放、SSO Token 加密与刷新轮换、并发提交串行化、取消后的工具消息配对修复。

## 未验证 / 限制

- 没有配置真实模型和实际 SSO/OA 账号，本轮未对真实人员执行授权，也未评估真实模型的指令理解率。
- 本机 Docker 引擎未运行，PostgreSQL 容器、镜像构建和容器间网络尚未验证；SQLite 验证不能替代 PostgreSQL 联调。
- 浏览器最终“确认分配”点击被自动审批拦截，理由为权限变更需要明确授权。没有绕过该拦截。对应服务端确认执行逻辑已由隔离自动化测试覆盖，但不宣称完整浏览器确认成功。
- 桌面 EXE 已打包，原生 WebView 中的 SSO 网络/跨域连接尚未实际验证；浏览器验证不能替代桌面运行验收。
